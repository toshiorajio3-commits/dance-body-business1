# RHYTHM BATTLE DEMO

Godot 4 系で動く、コードだけで作った「ネオン・リズムRPGバトル画面」の1画面デモです。外部画像素材・外部音源は使っていません。

## 起動方法

1. Godot 4 をインストールします。
2. このフォルダを Godot のプロジェクトとして開きます。
3. `Main.tscn` を実行します。

コマンドラインから確認する場合:

```bash
godot -d Main.tscn
```

環境によって実行ファイル名が `godot4` の場合があります。

```bash
godot4 -d Main.tscn
```

## 操作方法

| 操作 | 効果 |
| --- | --- |
| Space | ダウンビート攻撃。ビートに近いほど高ダメージです。 |
| R | グルーヴバースト。ビートリングの派手な演出と大ダメージです。 |
| H | 脱力リカバー。主人公のHPを回復します。 |
| Escape | バトルをリセットします。 |
| 画面下のボタン | キーボードと同じコマンドをクリックで使えます。 |

## ファイル構成

- `Main.tscn`: ルートが `Node2D` のメインシーンです。
- `scripts/Main.gd`: 背景、キャラクター、UI、操作、HP変化、演出の主要処理です。
- `project.godot`: Godot 4 用のプロジェクト設定です。
